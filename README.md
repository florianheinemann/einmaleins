# Einmaleins-Dojo

Das Einmaleins spielerisch üben – mit Ninja, Laternen, Gürteln und einem Drachen.

- **Kleines Einmaleins (1er–10er):** Shuriken pro Reihe, Gürtel von Weiß bis Gold, Großmeister-Urkunde.
- **Großes Einmaleins (11er–15er):** Dan-Streifen am goldenen Gürtel, ein Drache, der mitwächst, Sensei-Titel mit geheimer Belohnung und Sensei-Modus („Kind stellt, Eltern rechnen“).

Eine einzelne HTML-Datei ohne Build-Schritt, installierbar als App auf dem Homescreen. Der Fortschritt bleibt im Browser des Geräts.

Live über GitHub Pages aus dem Branch `gh-pages`. Hinweise zum Entwickeln und Veröffentlichen stehen in [CLAUDE.md](CLAUDE.md).
